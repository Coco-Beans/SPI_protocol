# SPI Protocol

A robust and reusable implementation of the Serial Peripheral Interface (SPI) protocol designed for hardware description and digital system communication.

## 📌 Overview
This repository contains the design and implementation of the SPI protocol. SPI is a synchronous serial communication interface used primarily for short-distance communication in embedded systems, microcontrollers, and FPGAs. 

---

## 🔌 Features & Specifications
* **Synchronous Full-Duplex Communication:** Simultaneous transmission and reception of data.
* **Configurable Clock Polarity (CPOL) & Phase (CPHA):** Supports flexible SPI modes (Mode 0, 1, 2, 3).
* **Master/Slave Architecture:** Implements core controller/peripheral logic.
* **Configurable Data Width:** Easily adaptable for 8-bit, 16-bit, or custom data packet lengths.
* **Testbench Included:** Comprehensive simulation scripts to verify timing, signal integrity, and data correctness.

---

## ⚙️ Signal Descriptions

| Signal Name | Direction (Master/Slave) | Description |
| :--- | :--- | :--- |
| **SCLK** | Master (Out) / Slave (In) | Serial Clock generated by the Master |
| **MOSI** | Master (Out) / Slave (In) | Master Out, Slave In (Data line) |
| **MISO** | Master (In) / Slave (Out) | Master In, Slave Out (Data line) |
| **SS / CS** | Master (Out) / Slave (In) | Slave Select / Chip Select (Active Low typically) |
